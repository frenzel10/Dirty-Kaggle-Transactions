# Dirty-Kaggle-Transactions
- Cleaned and summarized a dirty financial transaction dataset from Kaggle.

## Goal
- Wanted to demonstrate data entry and cleaning for financial records. Then use cleaned data to extract insights.

## Tools
- Excel: filtering, sorting, conditional formatting, ranking formulas, pivot tables

## Process
1. Searched for large financial dataset with inconsistencies
2. Filtered & sorted table, removed duplicates
3. Formatted dates, highlighted incorrect dates
